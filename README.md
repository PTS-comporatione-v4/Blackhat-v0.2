## Čo ťa čaká

Morseovka v časovej reprezentácii. Dva signály, len jeden je pravý.

**CESTA A** — prvý signál:

`*.*.*.***...*.*...***.*.*...*.*...*.***...***.*.***.*...*.*.......*.*.*...*.***.*.*...*...*.***.***.*...***.*.***.***`

**CESTA B** — druhý signál:

`***.***.*.*...*.*...*.***...***.*.*...***.*...*.***.......***.*...*.***...*.*.*.*...***.***.***...***.*.*...*.***`

Lúšti sa na [cryptii.com](https://cryptii.com) → Morse code
(English, Representation: Timing, Signal on: `*`, Signal off: `.`, DECODE).
Odpoveď je CELÝ dekódovaný text.
